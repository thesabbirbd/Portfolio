## 1. Executive Summary & Root Cause Fixes

This major release (`v5.2.13` ➔ `v5.2.14`) addresses critical real-world usability feedback, visual overlap issues reported in user screenshots, and deep academic tooling expansion for Bangladeshi students and everyday users:

1. **Resolution of the Modal Overlap & Floating Toolbar Collision:**
   - **Root Cause Identified from Screenshot:** Ten core studio tools were rendering **both** `StudioWorkspaceShell` **and** `UniversalStudioShareBar` inside the same view. This resulted in duplicate stacked toolbars, duplicate *"সহজ বাংলায় গাইড দেখুন"* buttons, and the `WorkplaceQuickDock` pill strip showing through/behind the modal dialog. Furthermore, in light mode, lede descriptions and small text had insufficient contrast (`text-neutral-300` on light background).
   - **Solution Implemented:** 
     - Upgraded `StudioWorkspaceShell` to be the single, unified master header across all studio tools. It now natively handles 24h encrypted sharing (`ShareContentModal`), user XP leaderboard badges, star/pin toggling, fullscreen Zen mode (`F`), cross-tool pipeline bridge (`StudioPipelineBridge`), Bengali guide modal (`BanglaGuideModal`), and embed widget shortcuts.
     - Removed the redundant `<UniversalStudioShareBar ... />` from all 10 studio tools (`AgeHealthCardStudio`, `BanglaConverterStudio`, `CgpaCalculatorStudio`, `ElectricitySolarStudio`, `EventDawatPlannerStudio`, `FamilyBudgetZakatStudio`, `HouseRentStudio`, `IdCardStitcherStudio`, `MedicineSchedulerStudio`, `TaxSanchaypatraEmiStudio`).
     - Added `pb-36` bottom padding to prevent bottom docks (`IdentityDock`, settings, terminal) from obscuring inputs.

2. **Complete Bangladeshi University & Polytechnic CGPA Engine:**
   - Expanded `DEGREE_PROGRAMS` in `src/lib/education/cgpa-grade-engine.ts` from 4 initial programs to **16 full 4-year degree programs** across 4 categories:
     - **BSC Engineering & Science (4 Programs):** CSE, EEE, Civil Engineering (CE), Software Engineering (SWE).
     - **BBA Business Administration (4 Programs):** General BBA, Accounting & Information Systems (AIS), Finance & Banking, Marketing & Digital Brand Strategy.
     - **BA / BSS Arts & Social Sciences (4 Programs):** English Literature & Linguistics, বাংলা ভাষা ও সাহিত্য (Bangla), Economics (B.S.S.), Islamic Studies & Culture.
     - **DIPLOMA Engineering - BTEB (4 Programs):** Computer Technology, Electrical Technology, Civil Technology, Mechanical Technology.
   - Every program includes full **8 semesters** (4 academic years) with authentic Bangladeshi course codes, course titles, credits, and UGC/BTEB grade point defaults.
   - Built an interactive **Year-by-Year Stepper Workflow** (`১ম বর্ষ` ➔ `২য় বর্ষ` ➔ `৩য় বর্ষ` ➔ `৪র্থ বর্ষ`) with automatic progress calculations, LocalStorage persistence, WhatsApp result sharing, and high-resolution A4 PNG transcript export.

3. **Neural Background Remover System Agent (`/tools/bg-remover`):**
   - Replaced client-side chroma-key flood-fill with a photographic AI neural cutout agent running locally via `rembg` (v2.0.87) with the cached `silueta.onnx` model (44.2MB).
   - Executed via backend API route `/api/tools/bg-remover` using child process streaming in ~2 seconds.

4. **Landing Page Clean Clickable Directory (`/`):**
   - Removed heavy execution sandboxes from the homepage.
   - Introduced `EverydayToolsAndNewsDirectory.tsx` featuring 12 newly launched everyday studios, curated tech news pulse, and core OS hubs.

## 3. High-Contrast Typography & Visual Separators

- **WCAG AAA Compliance Tokens:**
  - Added semantic classes `.surface-well`, `.surface-terminal`, `.badge-brand`, `.badge-ok`, `.badge-warn`, `.pro-input`, and `.pro-select` in `src/app/globals.css`.
  - Audited all 78 token-to-background combinations in `scripts/qa/a11y-contrast-verify.mjs` (100% pass across Light & Dark modes for Orange, Green, and Blue themes).
- **Text Shadows & Risky Area Legibility:**
  - Applied `drop-shadow-xs` and `drop-shadow-sm` on small-to-medium typography across studio cards, ensuring zero wash-out over subtle background grids and radial auroras.
  - Replaced hardcoded `text-neutral-300` on light background with semantic `text-neutral-800 dark:text-neutral-200` and `text-ink` / `text-ink-2`.
