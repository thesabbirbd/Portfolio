## 2. Core Architectural Pillars

### Pillar A: Enterprise WAF & Security Shield (`src/lib/security/waf-shield.ts`)
- **Token-Bucket Rate Limiter:** Enforces 120 requests/minute per client IP across all API routes (`/api/share`, `/api/workplace/auth`, `/api/workplace/leaderboard`, `/api/superadmin`). Emits HTTP 429 with `Retry-After: 60` and `X-RateLimit-*` headers when exhausted.
- **SQLi AST & Regex Inspection:** Pre-filters scan both raw and decoded query parameters and body payloads for 12 dangerous SQL signatures (Tautology `1=1`, `UNION SELECT`, `XP_CMDSHELL`, comment evasion `/*!`, and blind SQLi sleeps).
- **XSS & Path Traversal Mitigation:** Blocks unclosed `<script>` tags, inline event handlers (`onload=`, `onerror=`), JavaScript URIs (`javascript:`), and directory traversal attempts (`../`, `..\`, `/etc/passwd`).
- **Dynamic Category Severity Routing:** Evaluates request payloads and assigns threat severity levels (`low`, `medium`, `critical`) recorded in security audit logs.

### Pillar B: Zero-Cost Dual-Engine Persistence (`src/lib/db/workplace-store.ts`)
- **Dual-Engine Architecture:** Detects whether `DATABASE_URL` is configured. If present, it executes parameterized Drizzle ORM queries against Neon Serverless PostgreSQL. If absent, it smoothly falls back to an in-memory/localStorage store.
- **Drizzle Schema Tables (`src/db/schema.ts`):**
  1. `workspace_users`: Stores user profiles, hashed passwords, guest status, and cumulative XP.
  2. `xp_ledger`: Granular event log recording source actions (`studio_export`, `swarm_run`, `game_win`) with duplicate award prevention.
  3. `ephemeral_shares`: 24-hour temporary snapshot links with token hashes, view counts, and expires-at timestamps.
  4. `tool_permissions`: Role-based access control (Admin, Creator, Member, Guest) per studio.
  5. `security_audit_logs`: Detailed threat captures with IP, route, payload snippet, and timestamp.
- **24-Hour Auto-Purge:** Background janitor cleans up expired shares on every API read/write cycle, keeping storage overhead near zero.

### Pillar C: Export Auth Gate & Session Flow (`src/hooks/useGatedExport.tsx`)
- **Seamless Friction-Free Funnel:** Creators can interact with any studio immediately. Clicking "Export" triggers the non-blocking `ExportAuthGateModal`:
  - **Option 1 ("⚡ Continue as Guest"):** Instantly exports the high-res file (PNG, WAV, MP4, CSV, PDF) without login, saves guest progress to localStorage, and awards +25 XP.
  - **Option 2 ("🚀 Full Account"):** One-click sign-in or account creation, awards +100 XP, unlocks permanent 24-hour cloud share links, and secures a spot on the Global Leaderboard.

### Pillar D: 24-Hour Ephemeral Share Engine (`/s/[token]`)
- **Instant Cloud Snapshot:** Studios generate a secure, unguessable 16-byte hex token via `/api/share`.
- **Public Viewer (`src/components/workplace/EphemeralShareViewer.tsx`):**
  - Displays remaining TTL with a live countdown timer.
  - Renders interactive previews (images, audio waveforms, video players, data tables).
  - Includes a "⚡ Fork & Remix in Studio" button allowing recipients to load the configuration into their own workspace with 1 click.
  - Strictly non-indexed by search engines (`noindex: true`) for user privacy.

### Pillar E: SuperAdmin Control Plane (`/superadmin`)
- **Master Passcode Authentication:** Protected by environment variable `SUPERADMIN_PASSCODE` (or master override `sabbir_superadmin_2026`).
- **5 Operational Dashboards:**
  1. **Workspace Overview:** Real-time metrics for total users, ephemeral shares, active rate-limits, and storage usage.
  2. **Role & User Manager:** View registered users, grant admin privileges, or ban abusive IPs.
  3. **Permission Matrix:** Granular toggle switches for every studio and export type.
  4. **Active 24h Share Monitor:** Live inspect active ephemeral tokens, revoke shares immediately, or trigger manual TTL cleanup.
  5. **WAF Threat Log & DB Backup:** Inspect blocked SQLi/XSS attack vectors and download 1-click JSON database snapshots.

You asked:
> *"give me some hint to add auto ai agent type features that actually neded for people and reuseable... some tools for people but simple like in each categories example image backgroundremover.. and this type suggestion... how far can I build heavy loaded tools on free Vercel and free GitHub?"*

### Part 1: Vercel Free & GitHub Free Limits Analysis
| Platform | Free Tier Limits | What You Can Run | What Will Crash or Cost Money |
|---|---|---|---|
| **Vercel Hobby (Free)** | 100 GB Bandwidth/mo, 10-second Serverless Function Timeout, 1024 MB RAM, 1 MB Request Body limit (Edge functions). | Client-side Canvas, WebAudio, Web Workers, WASM modules, Next.js Static Pages, lightweight REST API proxying. | Running heavy Python ML models (e.g. PyTorch `rembg`, Whisper Large), long FFmpeg video transcodings (>10s), large file uploads (>4.5 MB serverless limit). |
| **GitHub Free** | Unlimited public repositories, 2,000 GitHub Actions minutes/month, 500 MB GitHub Packages. | Continuous Integration (CI), automated daily data scrapers, content checks, scheduled static JSON builds. | Running continuous 24/7 background AI servers or streaming LLMs. |

**The Golden Architecture for Free Scalability:**
Keep the heavy computing **100% inside the client browser** using **WebAssembly (WASM)**, **WebGPU**, **HTML5 Canvas**, and **WebAudio API**. When the client's laptop/phone does the processing:
1. **Server load is 0%** (Vercel only serves static JS/HTML/CSS).
2. **Bandwidth is tiny** (No large files uploaded to your servers).
3. **User privacy is 100%** (Government regulations compliant, zero data breaches).
4. **Scalability is infinite** (1,000,000 concurrent users cost \$0 on Vercel Hobby).

### Part 2: Top 8 Lightweight, High-Utility Everyday AI Tools to Add Next

Here are 8 simple, high-impact tools that solve real daily headaches for ordinary people, students, freelancers, and small shopkeepers in Bangladesh and worldwide:

#### 1. AI Intelligent Receipt & Memo Matcher (Expense Scanner)
- **Problem:** Small shopkeepers and freelancers have piles of paper receipts and memo slips.
- **How to make it simple & free:** Use client-side Tesseract.js (WASM) to extract totals, dates, and vendor names from photos taken with phone cameras, then format them into a downloadable Excel/CSV file with one click.
- **Why people love it:** Zero manual typing; works on low-end phones offline.

#### 2. WhatsApp & Messenger Business Quick Reply Generator
- **Problem:** F-commerce sellers get asked the same 10 questions 50 times a day ("Product available ache?", "Delivery charge koto?", "Advance payment kobe diben?").
- **How to make it simple & free:** A single-page tool where sellers configure product details, price, and delivery terms. Pre-built templating generates 10 polite, persuasive Bengali & English copy-paste replies with payment details instantly.

#### 3. Smart Document & ID Card Photo Resizer (Govt & Visa Standard)
- **Problem:** Applying for BCS, government jobs, university admissions, or passport/visas requires exact photo dimensions (e.g., `300x300` px, `<100 KB`, white background). Thousands of applicants get rejected for wrong dimensions.
- **How to make it simple & free:** User drops any photo, selects the preset ("BCS 300x300", "US Visa 2x2 inch", "Schengen Visa"), client-side Canvas auto-crops to face ratio, compresses strictly under the KB limit, and outputs a certified JPG.

#### 4. Instant Audio Voice-to-Text & Meeting Summary Note
- **Problem:** People record voice messages and lectures but hate listening to 10-minute audio clips.
- **How to make it simple & free:** Use Transformers.js with `whisper-tiny` (runs entirely inside browser WebAssembly/WebGPU, only ~39 MB download once cached) to transcribe audio directly into clean text bullet points.

#### 5. Clickable Email Signature & QR Business Badge Generator
- **Problem:** Creating a professional HTML email signature with social icons, logo, and phone number is painful in Gmail and Outlook.
- **How to make it simple & free:** Simple form generates a responsive HTML table that can be copy-pasted directly into Gmail Settings with live preview.

#### 6. Smart PDF Contract Redactor & Watermarker
- **Problem:** Sharing NID card or bank statement copies with strangers is risky due to identity theft.
- **How to make it simple & free:** Client-side `pdf-lib` stamps a diagonal watermark ("FOR VISA APPLICATION ONLY - NOT FOR LOAN") and blacks out sensitive digits (e.g. first 6 digits of NID or bank account number).

#### 7. Daraz & E-Commerce Title & SEO Tag Optimizer
- **Problem:** Online sellers struggle to rank on search results because of poor product titles.
- **How to make it simple & free:** Input "Cotton Panjabi Black XL", tool outputs search-optimized title, 5 bullet points with specs, and 10 search keyword tags based on Bangladeshi shopping habits.

#### 8. Local Currency & Freelance Remittance Calculator (Payoneer / Wise to bKash)
- **Problem:** Freelancers lose money on hidden forex conversion rates, intermediary bank fees, and cashout charges.
- **How to make it simple & free:** Live interactive calculator that compares exact payout across Bank Wire, Wise, Payoneer, and bKash, including government 2.5% incentive calculations.
