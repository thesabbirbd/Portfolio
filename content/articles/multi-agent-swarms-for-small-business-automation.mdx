## The Failure of Monolithic "Do Everything" Prompts

Asking a single AI model or agent to handle a complex multi-disciplinary task (for instance: "take this raw memo image, verify its math, generate accounting CSVs, write an audit summary in Bangla, and redact all customer phone numbers") frequently collapses into conversational hallucinations and missed edge cases.

A monolithic prompt divides the model's attention budget across too many conflicting objectives.

---

## 1. The DAG Swarm Architecture: Chained Specialization

The proven enterprise solution is a **Directed Acyclic Graph (DAG)** of specialized autonomous agents. Each agent acts as an independent specialist with strict boundary schemas:

```
Input Data ──▶ [Agent 1: Extractor] ──(Artifact A)──▶ [Agent 2: Auditor] ──(Artifact B)──▶ [Agent 3: Sanitizer] ──▶ Final Bundle
```

### Real-World Production Pipeline: Daily Shop Closing Swarm
1. **KhataVision Agent (Stage 1):** Focuses solely on reading ledger line items, converting Bengali digits to numerals, and verifying total column balances.
2. **ChequeGuard Agent (Stage 2):** Ingests Stage 1's structured totals, calculates exact Taka-in-Words in Bengali (`এক লক্ষ পঁচিশ হাজার টাকা মাত্র`), and audits bank deposit slips.
3. **PrivacyShield Agent (Stage 3):** Scrubs private customer contact information, phone numbers, and signatures before writing the final archived daily reconciliation report.

## 2. In-Memory Context Handoff & Zero-Leakage Safety

In client-side agent orchestration, the state machine passes typed JSON artifacts in memory across stages without storing unencrypted tokens on intermediate databases:

```typescript
export interface SwarmStageResult {
  agentId: string;
  stageName: string;
  outputPayload: Record<string, unknown>;
  markdownArtifact: string;
  durationMs: number;
}

export async function executeSwarmPipeline(
  pipeline: SwarmPipelineConfig,
  input: string
): Promise<SwarmExecutionResult> {
  let context = input;
  const traces: SwarmStageResult[] = [];

  for (const stage of pipeline.stages) {
    const res = await stage.agent.execute(context);
    traces.push(res);
    context = res.markdownArtifact; // Chained handoff
  }

  return assembleBundle(traces);
}
```

## Business Impact

By decomposing complex tasks into discrete autonomous swarms:
- Verification errors drop to virtually zero.
- Execution steps are fully auditable with transparent visual handoff logs.
- Small businesses and solopreneurs gain the equivalent output of an entire multi-department operations team.
