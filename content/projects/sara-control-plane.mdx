## Overview

Managing homelab infrastructure, video rendering pipelines, and background database backups often requires immediate remote intervention without exposing SSH ports to the public internet.

**S.A.R.A. (System Automation & Remote Agent) Control Plane** is a self-hosted orchestration service. It turns an authenticated private Telegram chat into a secure, responsive remote command center for developer workstations and local servers.

## Key Capabilities

- **Secure Telegram Remote Terminal:** Authenticated via user ID cryptographic hash checking. Execute pre-approved operational runbooks (e.g., restart service, inspect journalctl logs, trigger database snapshot) without opening WAN ports.
- **Persistent Job Queue:** If the host loses connectivity or reboots, in-flight jobs remain queued in an atomic SQLite database with WAL (Write-Ahead Logging) enabled.
- **Proactive Health Telemetry:** Automatically notifies the administrator when disk space drops below 15%, memory exceeds 90%, or the local UPS switches to battery power during load shedding.
- **Resource Sandboxing:** Shell scripts run under an unprivileged system user with strict timeout thresholds (max 120s) and cgroup memory limits.
