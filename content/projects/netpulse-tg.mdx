## Overview

In mission-critical retail and edge computing environments across Bangladesh, intermittent fiber breaks and upstream ISP packet degradation can quietly paralyze POS terminals and cloud sync daemons.

**NetPulse TG** is a containerized infrastructure watchdog engineered to continuously probe upstream gateway health, evaluate round-trip jitter, and instantly notify network administrators via Telegram long before end users experience outages.

## Key Capabilities

- **High-Frequency Gateway Probing:** Executes configurable sub-second ICMP and TCP ping sweeps against multiple reference DNS servers and local ISP BDIX gateways.
- **Jitter & Degraded State Machine:** Detects soft degradation (packet loss exceeding 8% or latency variance >50ms) before a total link drop occurs, suppressing false-positive notification storms.
- **Instant Telegram Incident Dispatch:** Sends structured Markdown incident alerts detailing packet loss percentages, hops affected, and estimated recovery times.
- **Zero-Cloud Architecture:** Operates entirely within local Docker containers or lightweight edge devices with Prometheus metrics exposed on a local port.
